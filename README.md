# VELOOP – Data Analytics & Data Readiness Assessment

## Project Overview
This project focuses on performing a comprehensive data analytics and data readiness assessment for VELOOP, a simulated rewards-based digital platform.

The objective is to evaluate user activity, engagement, rewards, wallet transactions, withdrawals, referrals, and feature usage through Python and SQL.

**Note:** The dataset used in this assignment is fictional and simulated for analytical and educational purposes.

## Project Objectives
- Understand the overall data structure and quality.
- Perform data profiling and exploratory data analysis (EDA).
- Identify missing values, duplicate records, and inconsistent data.
- Analyze user registration and engagement patterns.
- Evaluate task activity and reward distribution.
- Examine wallet transactions and withdrawal behavior.
- Analyze referral performance.
- Identify data quality issues and recommend improvements.
